# 连接面板：基础连接与参数作用域重整（P0）

## 1. 目标与定案

连接面板必须让用户在保存前就能判断“这次会写到哪里”。现有面板把全局 API 预设、对话独立 API 参数和当前 `panel-live` 运行态混在同一个表单与保存路径中，容易产生回滚、误写和无法解释的显示切换。

本次定案：

1. **API 基础设定只属于全局 API 预设**：预设别名、Base URL、API Key 不提供对话覆盖，也不随参数 Tab 切换。
2. **只有 API 参数设定具有作用域**：模型、生成/采样参数、流式传输、思维链、DRY 与自定义参数可在“对话”和“全局”间切换。
3. **对话 Tab 永远可用**；进房时按是否继承全局打开对应 Tab（继承 → 全局，独立 → 对话）。其中的“继承全局参数”开关是该对话参数是否独立的唯一入口。
4. 打开“继承全局参数”时，对话实际使用全局预设参数；全局 Tab 可切换和编辑。关闭它时，对话读取自身独立参数；若尚无独立参数，则以当时的全局参数复制出一份对话参数快照。独立模式下禁用全局 Tab。快照使用 `apiPreset.chat.inheritGlobal` 表示“保存但暂不生效”，并**保留 `apiConfigId` 与参数字段**，因此重新关闭继承可恢复原绑定预设与参数，而不依赖前端临时状态。
5. API 基础设定的保存只改全局预设；独立模式的参数保存只改当前对话。连接面板只保留一个页脚“保存”按钮，并合并为一次成功反馈。
6. **不存在 panel-live 通信状态**：聊天请求只给出会话身份；服务端从已经保存的对话设置与全局预设解析有效参数。前端草稿不参与请求参数。
7. 连接面板打开时遮罩主对话并**禁止一切出站**（发送 / 再生 / 群聊继续等，经 `prepareOutboundRequest` 统一拦截）；若任一草稿为 dirty，不能直接关闭。用户只能“保存并关闭”或取消关闭并继续编辑。保存失败也必须留在面板内；页脚保存成功后关闭面板。无 dirty 时页脚保存不写盘。

## 2. 信息架构

```text
连接（模态弹窗）

桌面（>800px）双列，各自独立滚动：
  左：API 基础设定（全局 API 预设）
    预设别名 | Base URL | API Key
  右：API 参数设定
    [ 全局 | 对话 ]
    对话：[继承全局参数]
    模型 / 生成参数 / 流式 / 思维链 / 温度等 / DRY / 自定义参数

窄屏（≤800px）：顶部 Tab「API 基础设定 | API 参数设定」切换同一两列内容（v-show 保挂载以免丢草稿）

页脚：[保存]
```

两侧列标题仅在桌面双列显示（与窄屏顶部 Tab 文案一致）；窄屏不重复标题。弹窗外壳为 flex（工具栏/页脚不缩，中间滚动区吃剩余高度）；窄屏用 `content-class` 限宽并居中，避免全站 overlay 最小宽度把弹窗挤偏。

“对话”Tab 始终可用。进房默认 Tab：继承全局时打开「全局」，独立参数时打开「对话」。继承开启时，参数控件显示全局解析结果但不可将其作为对话覆盖保存；用户可切到全局 Tab 修改全局参数。继承关闭时，对话 Tab 可编辑并保存对话参数，全局 Tab 禁用，防止用户在当前对话已声明独立参数时误以为两个目标会同时生效。两处预设选择器使用同一绑定并保持同步；重新启用继承时自动切换到全局预设，磁盘快照仍保留原 `apiConfigId`。

## 3. 数据与运行时契约

### 3.1 基础连接

基础连接字段的唯一真相源是全局 `ApiPreset`。无论当前处在何种对话、参数 Tab 选中哪一项，都不得把 Base URL、API Key 或预设别名写入对话 `apiPreset.chat` 覆盖对象。

对话既有的 `apiConfigId` 绑定语义保持不变：它引用全局预设，而非复制或私有化连接凭据。若未来需要在连接面板调整该绑定，必须作为“选择对话绑定预设”的显式动作实现，不得借由保存基础字段隐式变更。

### 3.2 参数

全局参数的唯一真相源为选中 `ApiPreset` 的默认参数；关闭继承后的对话参数唯一真相源为当前对话 `apiPreset.chat` 的允许覆盖字段。对话有效参数由“其绑定预设的全局参数 + 对话覆盖”解析，但保存对话 Tab 时只写覆盖字段，保存全局 Tab 时只写预设字段。

进入对话时默认装载“对话”Tab，并依继承开关决定展示全局解析值或独立参数。关闭继承的首次操作必须把当前全局参数完整复制为对话快照；此后全局参数的修改不再改变这份快照。开关本身参与对话状态的保存：开启继承后保留但不使用已有对话快照，关闭后优先恢复该快照；仅在快照不存在时才新建复制。切换 Tab 或切换继承状态必须显式处理未保存修改（确认丢弃或取消切换），绝不静默把一侧表单写到另一侧。

请求发送只携带 `conversationId` 等业务身份，服务端读取持久化的全局预设、对话 `apiConfigId` 与继承/独立参数状态后解析有效参数。前端不得发送 `panelLive`、草稿采样参数或其它可覆盖服务端设置的参数。保存成功后再刷新对应作用域的 baseline；不得让 unrelated watcher 用另一作用域或旧 baseline 回灌当前正在保存的表单。

### 3.3 关闭与未保存草稿

连接面板是模态遮罩，打开时不能发送聊天消息。基础设定列与参数设定列各自独立滚动，避免一侧滚动影响另一侧。关闭动作是保存边界：若基础设定或当前参数作用域有未保存修改，关闭按钮必须改为/触发“保存并关闭”；取消则继续停留在面板。页脚只提供一个“保存”按钮，统一保存当前 dirty 作用域并给出一次成功反馈。不得提供“忽略并关闭”“保持草稿继续通信”或把草稿临时注入下一次聊天请求的路径。

## 4. 实施计划

### P0-1：梳理字段与 API 边界

- 列出 `ApiPreset`、`apiPreset.chat` 和 panel-live 现有字段，确定对话允许覆盖字段白名单。
- 将基础字段和参数字段拆成明确 DTO/保存函数；禁止通过同一个完整表单 payload 推断保存目标。
- 保留既有 `apiConfigId` 绑定；不增加 Base URL/API Key 的对话兼容字段或双写路径。
- 删除/拒绝聊天请求中的 panel-live 参数；服务端成为有效 API 参数解析的唯一入口。

### P0-2：重构连接面板状态

- 基础设定表单始终绑定预设编辑状态。
- 参数表单按 `parameterScope = conversation | global` 分别保存 dirty/baseline/载入指纹，避免作用域切换互相污染。
- 对话 Tab 永远可用；进房按是否继承全局打开对应 Tab；实现“继承全局参数”开关。关闭继承时，若没有独立设置则从全局复制完整参数快照，并禁用全局 Tab；开启继承时保留但不使用对话快照（含 `apiConfigId`），并重新允许全局 Tab。

### P0-3：重构保存与 hydration

- 基础设定、对话参数、全局参数仍调用作用域明确的持久化路径，但由页脚单一“保存”按钮统一提交并只发出一次成功反馈。
- 连接面板保存期间，相关 hydration 必须等待该作用域 baseline 刷新；其它作用域不得复写当前表单。
- 侧栏 dirty 时拦截关闭，只允许保存成功后关闭；保持上一个 P0 已修复的保障：异步 PUT 期间旧会话快照不能回灌面板。
- 删除 panel-live 组装、传输、服务端优先级分支及其测试，改由服务端读取已保存设置完成解析。

### P0-4：验收与回归

- 组件/Store 测试覆盖：继承开关的开/关和首次复制、已有独立设置默认对话 Tab、独立模式禁用全局 Tab、Tab/开关切换脏状态、三种保存目标、异步保存期间 watcher 触发、dirty 时无法关闭侧栏。
- 服务端测试覆盖：聊天请求不接受 panel-live 覆盖，且仅由持久化的对话/全局设置解析有效参数。
- 浏览器覆盖：修改基础连接只影响预设；关闭继承后保存对话参数只改变该对话；开启继承后全局参数影响该对话；独立模式全局 Tab 不可用；有未保存修改时不能关闭；保存后关闭再发消息时请求参数与服务端保存值一致。
- 运行 `npm test -w server`、`npm run typecheck -w web`、`npm run check:host-no-plugin-ids`、`git diff --check`。

## 5. 非目标

- 不创建每对话独立的 Base URL、API Key 或预设副本。
- 不为旧字段/旧保存 API 保留兼容双写或运行时迁移。
- 不改变 `apiConfigId` 现有绑定语义；该项如需体验优化另立明确任务。
