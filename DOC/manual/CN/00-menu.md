# 新手教程目录（中文）

面向第一次使用 arousalPub 的读者：按分区顺序做完，即可完成「安装 → 连上模型 → 导入角色 → 开聊」整条路径。

编号规则：**A** 必做 · **B** 推荐 · **C** 部署 · **D** 进阶（区内按序号阅读）。

进阶开发 / 插件定案请看 [`../../devNotes/`](../../devNotes/)，不要从这里起步。

[English manual](../EN/00-menu.md) · [English README](../../../README.md) · [中文说明](../../README.zh.md)

---

## 怎么读

1. 建议先按 **A → B** 读；**C / D** 按需。
2. 每一章只办一件事，做完再进下一章。
3. 文中「点击 / 打开」均以默认本地启动（`http://localhost:6633/`）为准。
