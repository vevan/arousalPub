## 步骤

### 1. 新建对话

在首页点击 **「新建对话」**。

### 2. 填写创建表单

| 项 | 建议 |
|------|------|
| **对话名称** | 任意，方便以后在列表里找到 |
| **用户卡** | 选用户角色（没有可先不纠结，按界面可选内容选） |
| **主角色卡** | 选对方角色；需要多角色时可 **添加角色槽**（群聊见 [14](14-group-and-branches.md)） |
| **绑定资料库** | 新手可先用默认勾选，或清空后再开聊；资料库详见 [08](08-lorebooks-intro.md) |

点击 **「开始对话」**。

### 3. 发送第一条消息

1. 在底部输入框输入内容。
2. 发送（具体快捷键可在 **设置 → 系统** 里查看/修改）。

若配置正确，助手回复会**流式**出现。若顶栏仍提示去配「连接」，回到 [03 · 连接 API](03-connect-api.md)。
