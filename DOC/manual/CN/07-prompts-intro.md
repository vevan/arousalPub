## 打开提示词库

顶栏点击 **「提示词」**，打开 **「提示词」** 管理界面。

结构是：

**预设 → 分组 → 条目**

条目上可配置触发方式、注入位置等。新手不必一次改完所有条目：先用自带或导入的预设开聊，再慢慢调。

---

## 设为默认（全局）

在提示词库中，可对某个预设使用 **「设为默认预设」**。  
「连接」面板也可 **关联提示词预设**（设全局 API 预设时可能自动带上）。

默认预设会影响「跟随全局」的对话。

---

## 给本场对话绑定

1. 打开一场对话。
2. **本对话设置 → 绑定 → 提示词预设**。
3. 选一个具体预设，或保持 **「跟随全局当前预设」**。

这样同一账号下不同对话可以用不同提示词策略。

---

## 从 SillyTavern 导入预设

- 提示词库内：**「导入预设…」**
- 或 **设置 → 导入**，再选打开提示词库导入

更完整的迁移说明见 [16 · 从 SillyTavern 迁过来](16-from-sillytavern.md)。
