# 09 · 资产库（文件）入门

## 这是什么

顶栏 **「文件」** 打开的是统一的**媒体与文档柜**：

| Tab | 用途 |
|-----|------|
| **资产库** | 上传、预览、管理图片 / 文档 / 音频 / 视频 |
| **知识库** | 把已上传的**文档**编成集合，做切片与向量召回（需 Embeddings，见 [11](11-vector-recall.md)） |

它**不是**资料库（世界书）。资料库是手工条目；资产库是文件本体。两者互不替代。

没有「文件夹」概念：用**类型筛选**（全部 / 图片 / 文档 / 音频 / 视频）和**标签 / 搜索**整理即可。

---

## 打开与上传

1. 顶栏点 **「文件」**。
2. 确认在 **「资产库」** Tab。
3. 点 **「上传」**，可选多张（图片、txt/md/json/pdf、常见音频视频等）。
4. 左侧网格选中文件，右侧可预览；可 **重命名**、**编辑标签**、**复制 URL**、**更新**（换内容保留同一条目）、**删除**。

**内容 URL**（`/api/m/…`）可直接用在气泡图片等场景。有引用时删除可能提示 **清除引用并删除**——背景、BGM、角色绑定、知识库都可能受影响。

---

## 工作流 A：对话背景

1. 在资产库上传一张**图片**。
2. 打开某场对话 → **本对话设置 → 绑定 → 对话背景**。
3. **从资产库选择**（或 **更换** / **清除**）。

---

## 工作流 B：对话 BGM

1. 上传一段**音频**。
2. **本对话设置 → 绑定 → 对话 BGM** → 从资产库选择。
3. 进入对话后音乐会循环播放；顶栏可 **静音 BGM** / **取消静音 BGM**。

---

## 工作流 C：给角色绑文件（可选）

1. 先在 **文件 → 资产库** 上传（角色页**不能**直接上传）。
2. 顶栏 **角色** → 选中角色 → **资产库绑定** → **从资产库绑定**。
3. 数量有上限（界面会提示，常见为最多 30 个）。

高级用法可在提示词里用文件相关宏引用绑定图；新手可先只做绑定与预览。

---

## 工作流 D：文档进知识库（概述）

1. 在资产库上传 **文档**（建议 `.txt` / `.md`；PDF 可入库，但 RAG 切片支持有限）。
2. 同一模态切到 **「知识库」** Tab：新建知识库 → **添加文档** → 需要时 **重建索引**。
3. **本对话设置 → 绑定 → 知识库** 勾选要参与召回的库。

全局 Embeddings 与知识库 RAG 开关在 **设置 → 向量召回**（[11 · 向量召回](11-vector-recall.md)）。未配 Embedding 时，上传与管理文件仍可用，文档召回不可用。

---

## 与「绑定」Tab 的对照

| 本对话设置 → 绑定 | 文件从哪来 |
|-------------------|------------|
| **对话背景** / **对话 BGM** | 资产库里的图片 / 音频 |
| **知识库** | 资产库文档 → 知识库 Tab 编组后再勾选 |
| **资料库** | 世界书（[08](08-lorebooks-intro.md)），不经过资产库 |

---

## 自检

- [ ] 顶栏 **文件** 能打开，并在 **资产库** 成功上传至少一个文件。
- [ ] 能给某场对话设背景或 BGM（或至少打开过选择器）。
- [ ] 知道 **知识库** Tab 与 **资料库** 不是一回事。
