## 怎么打开

顶栏 **齿轮** → **「设置」**（全屏模态）。左侧是分类导航。

说明：API Key / 模型仍在顶栏 **「连接」** 面板，不在本页（见 [03](03-connect-api.md)）。

---

## 各 Tab 一眼看懂

| Tab | 你常改什么 |
|------|----------|
| **系统** | 界面语言、对话字号、输入框发送快捷键、会话块切分等 |
| **账号** | 头像、改密、默认用户、登出、删号（见 [02](02-first-login.md)） |
| **显示** | 主题与主色、首页默认视图等 |
| **对话历史** | 是否限制历史轮数、最多带多少轮进上下文 |
| **资料库** | 全局关键字递归等（单本内容仍在「资料库」页编辑） |
| **向量召回** | Embeddings、远期记忆、资料库向量、知识库 RAG——专章见 [10](10-vector-recall.md) |
| **预算裁切** | 上下文超预算时的丢弃顺序 |
| **正则替换** | 用户级正则管线 |
| **插件** | 启用、排序、各插件设置（见 [15](15-plugins-intro.md)） |
| **导入** | 从 SillyTavern 导入世界书 / 预设 / 聊天记录等（见 [16](16-from-sillytavern.md)） |
| **调试** | **会话 debug 审计**开关、版本信息、会话 debug 审计等（见 [17](17-session-debug-audit.md)） |

---

## 建议新手先动的两项

### 语言

**设置 → 系统**：**跟随浏览器语言** / **English（英语）** / **中文（简体）**。

### 主题

**设置 → 显示**：选主题与主色，按自己眼睛舒服即可。

其余选项等遇到具体需求再改；不必一次调完。
