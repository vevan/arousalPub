# B-01 · 对话里常用操作

完成本章后：会再生、翻看多条助手回复（swipe），并会在「本对话设置」里换角色或资料库。

## 重新生成

对某条助手回复，使用操作 **「再生」**（快捷键一般为 **R**）。

会再向模型请求一版回复；旧版本通常仍可通过 swipe 翻回（见下）。

---

## Swipe（多版本滑动）

助手消息旁可切换：

- **上一条助手回复**
- **下一条助手回复或重新生成**

界面会显示类似 **「第 x 条，共 y 条」**。适合对同一轮用户输入比较多个生成结果。

---

## 本对话设置

在对话页顶栏点 **齿轮**，打开 **「本对话设置」**。

### 「绑定」Tab（最常用）

| 项 | 作用 |
|------|------|
| **提示词预设** | 本场用哪套提示词；可「跟随全局当前预设」 |
| **用户 / 对方角色** | 换绑角色卡 |
| **资料库** | 勾选本场要注入的世界书（可多选，顺序影响合并） |
| **知识库** | 文档 RAG（文件先上传到资产库，见 [B-04](B-04-files-and-assets.md)） |
| **背景 / BGM** | 从资产库选图片/音频（见 [B-04](B-04-files-and-assets.md)） |

改完后继续聊即可，无需重建整场对话。上传文件本身在顶栏 **「文件」**，不在本面板。

### 其它 Tab（知道入口即可）

- **向量召回**：本场覆盖与 **重建记忆索引**（见 [B-07](B-07-vector-recall.md)）
- **正则批量**：对历史轮次套用 **落盘** 阶段规则（规则本身在设置里配，见 [B-06](B-06-regex-rules.md)）
- **插件**：本场覆盖全局插件默认（见 [D-02](D-02-plugins-intro.md)）
- **群聊**：多角色时再看 [D-01](D-01-group-and-branches.md)
