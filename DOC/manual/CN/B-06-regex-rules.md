# B-06 · 正则替换入门

## 正则是干什么的

**正则替换**是宿主自带能力（不是插件）：用一组规则对文本做查找替换。

- **作用范围**：当前登录用户级（`regex-rules.json`），对该账号下**全部对话**生效。
- **不是**按对话单独存一套规则；对话里只有「对历史批量套用落盘规则」的入口。

常见用途：去掉模型尾部追踪标签、统一省略号、清洗推理字段、改写发给模型前的正文等。

---

## 入口

1. 顶栏 **齿轮** → **设置**。
2. 左侧 **「正则替换」**。

列表可 **拖拽排序**（越靠上越先执行）；改完会自动保存。也可用 **管线测试** 在保存前试跑一段样本文本。

从 SillyTavern 迁过来时：**没有**一键导入 ST Regex Script；请在此页按需重建规则（角色卡 / 世界书 / 预设仍见 [D-03](D-03-from-sillytavern.md)）。

---

## 三条阶段（最重要）

每条规则可勾选一个或多个 **阶段**：

| 阶段 | 改什么 | 改磁盘上的聊天记录？ | 改下次发给模型的内容？ | 改界面气泡？ |
|------|--------|----------------------|------------------------|--------------|
| **显示（display）** | 渲染用的文本 | 否 | 否 | 是 |
| **出站（outgoing）** | 组装后的 prompt（含 system 等） | 否 | 是 | 否（不直接改气泡） |
| **落盘（persist）** | 写入磁盘前的 user / 助手正文 / reasoning | **是** | 是（经历史再进上下文） | 新消息落盘后可见 |

**新手建议**：

1. 新建规则默认往往只有 **显示**——先用显示阶段验证 pattern，再考虑出站 / 落盘。
2. **落盘** 会改真实历史；配错可能难恢复，请先备份或先用 **管线测试** / 对话内 **试运行**。
3. 只想「聊的时候模型看不见某段、但磁盘原样保留」→ 用 **出站**，不要用落盘。
4. 只想「界面好看、磁盘与发给模型的不变」→ 用 **显示**。

---

## 字段、跳过最近 N 轮、启用

| 项 | 说明 |
|----|------|
| **字段** | 可选 `system` / `user` / `assistant` / `reasoning`（按阶段实际会碰到的文本勾选） |
| **跳过最近 N 轮** | `0` = 凡命中都应用；`N≥1` = 最近 N 轮**不**套用该条（避免改到刚发出的几轮） |
| **启用** | 关掉则跳过执行，但仍占排序位置 |
| **Pattern / Flags / 替换** | 标准 JS 正则与 `String.replace` 替换串（支持 `$1`、`$&` 等） |

替换串里的**真实换行**有效；字面量两个字符 `\n` **不会**自动变成换行。

## 对历史批量套用（仅落盘阶段）

**落盘** 规则只自动作用于**之后新写入**的轮次。若要让**已经存盘**的旧消息也按新规则改一遍：

1. 打开该对话 → 顶栏 **本对话设置**（对话页齿轮）。
2. 打开 **「正则批量」**（或同等名称的 Tab）。
3. 勾选要应用的、已启用且含 **落盘** 阶段的规则。
4. 选轮次范围 → 先 **试运行** 看会影响多少轮 → 再 **应用**。

没有启用的落盘规则时，面板会提示先去 **设置 → 正则替换** 配置。

---

## 和审计的关系

开启 [会话 debug 审计](D-04-session-debug-audit.md) 后，性能 Tab 里可能看到 **出站正则**、**落盘正则** 等耗时；提示词 Tab 看到的是**已经过出站处理后**发给模型的内容。适合核对「出站规则有没有把不该删的删掉」。

---

## 建议怎么试

1. 加一条仅 **显示** 的规则（例如把连续三个点规范成省略号），看气泡是否变化、磁盘原文是否不变。
2. 再试一条 **出站**：在审计的「提示词」里确认发给模型的文本已变，气泡/落盘仍按你的预期。
3. 需要改历史时，用 **正则批量** 的试运行，确认范围后再应用。
