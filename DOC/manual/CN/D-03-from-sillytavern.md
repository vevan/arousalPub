# D-03 · 从 SillyTavern 迁过来

完成本章后：知道角色卡、世界书、提示词预设、聊天记录各自从哪导入，以及目前的限制。

## 总览

| 要带什么 | 在哪里导入 |
|----------|----------|
| **角色卡** | 顶栏 **角色** → **导入 JSON / PNG**（不在「设置 → 导入」里批量导角色） |
| **世界书** | **设置 → 导入 → ST 世界书 → 选择 JSON…**；或资料库页导入 |
| **提示词预设** | **提示词**库内 **导入预设…**，或 **设置 → 导入** 引导打开提示词库 |
| **聊天记录** | **设置 → 导入 → ST 聊天记录 → 选择 JSONL…** |

导入前建议先走完 [A-01](A-01-install-and-start.md)–[A-03](A-03-connect-api.md)，并准备好用户卡与对话角色（[A-04](A-04-characters.md)）。

---

## 角色卡

1. 打开 **角色库**。
2. **导入 JSON / PNG**。
3. 需要当「你」的卡，**标记为用户卡**（见 [A-04](A-04-characters.md)）。

---

## 世界书 / 资料库

1. **设置 → 导入**，选 ST 世界书 JSON；或  
2. **资料库**页 **导入资料库（追加一本）**。

导入后到具体对话里 **绑定** 该资料库（[B-03](B-03-lorebooks-intro.md)）。

---

## 提示词预设

在提示词库 **导入预设…**，再在对话 **绑定** 或设为默认（[B-02](B-02-prompts-intro.md)）。

宏与条目细节若有差异，以本应用实际渲染为准；兼容对照见开发文档，新手可先导入再试聊。

---

## 聊天记录（JSONL）

1. **设置 → 导入 → ST 聊天记录**。
2. 先选好 **用户角色（persona）** 与 **对话角色**。
3. 选择 JSONL；会**创建新会话**并导入。

注意：若目标会话已有消息，导入可能失败——请走「新建会话」这条导入路径。  
群聊多 bot 的历史映射仍可能有限，复杂群聊记录请导入后人工检查。

---

## 正则脚本

SillyTavern 的 Regex Script **目前不能**经「设置 → 导入」一键迁入。请在 **设置 → 正则替换** 按需重建；三阶段含义与历史批量套用见 [B-06 · 正则替换入门](B-06-regex-rules.md)。
