# D-05 · 第一方插件使用指南

完成本章后：知道仓库自带的 7 个插件各自做什么、如何启用，以及在对话里从哪里操作。

上一章：[D-04 · 会话 debug 审计](D-04-session-debug-audit.md) · 下一章：[D-06 · 常见问题排查](D-06-troubleshooting.md) · [目录](00-menu.md) · [English](../EN/D-05-bundled-plugins.md)

插件通用入口（启用、排序、导入导出）见 [D-02 · 插件与扩展能力简介](D-02-plugins-intro.md)。本章只讲**第一方（随仓库捆绑）插件**的用法。

---

## 共用步骤

1. **设置 → 插件**：打开需要的插件开关；复杂插件点 **设置** 填 API 预设等。
2. 进入对话：多数插件在**输入框上方工具栏**或**助手/用户消息下方**出现按钮。
3. 需要仅本场生效时：**本对话设置 → 插件** 覆盖全局（部分插件支持）。

建议一次只启用一个你不熟悉的插件，确认行为后再开下一个。

---

## 剧情纪要（Historian / `plot-summary`）

**作用**：把一段对话摘要成条目，写入指定**资料库**，用于长线剧情记忆。

| 在哪用 | 做什么 |
|--------|--------|
| 输入框工具栏 | 手动摘要、选起止轮、开关**自动摘要**、本会话设置 |
| **本对话设置 → 插件** | 摘要写入哪本资料库、自动摘要、每块轮数等 |
| 输入框 slash | `/plot`、`/plot summary 99-150` 等打开手动摘要（见插件提示） |

**典型流程**：

1. **设置 → 插件 → 剧情纪要**：配置 API 预设、默认每 N 轮触发等。
2. 打开对话 → 工具栏 **本会话剧情纪要设置** → 选好 **摘要资料库**（与绑定 Tab 里「注入用资料库」不是同一概念）。
3. 聊一段时间后点 **手动摘要**，或开启 **自动摘要**（仍可能需预览确认后再写入）。

写入的是资料库条目；若要在对话里**注入**这些摘要，还需在 **绑定 → 资料库** 勾选该书（见 [B-03](B-03-lorebooks-intro.md)）。

## 迹录（Trace Keeper / `trace-keeper`）

**作用**：维护结构化「场景状态」（地点、时间、氛围等 JSON），在回复中或 Separate 补生成后展示在**左侧插件面板**。

| 在哪用 | 做什么 |
|--------|--------|
| 助手消息区域 / 左栏 **迹录** | 查看本轮 tracker、**重新生成 tracker（Separate）**、编辑 JSON |
| **设置 → 插件 → 迹录** | 默认套件、Separate API、注入顺序、套件模板与样式 |
| **本对话设置 → 插件** | 本会话套件、Separate 窗口轮数等 |

**典型流程**：

1. 启用插件并在全局设置里选好 **API 预设**（Separate 补生成用）。
2. 正常聊天；模型若在回复中带 `<ex-trace-keeper>{JSON}</ex-trace-keeper>`，左栏会渲染面板。
3. 若无 tracker 块，可在面板里 **重新生成 tracker（Separate）**。

## 指导生成（`guidance-generate`）

**作用**：发送时附带**隐藏指导文本**（不显示在聊天气泡里），或用指导 **再生 / 修改** 助手回复；**润色**标签页可美化用户输入。

| 在哪用 | 做什么 |
|--------|--------|
| 输入框工具栏 **指导生成** | 打开对话框：**生成**（指导发送）或 **润色** |
| 助手消息下方 | **指导修改**（以当前回复为基准按指导改写） |

**典型流程**：

1. 启用插件（可选在 **设置 → 插件** 里改系统前缀、润色历史轮数）。
2. 点工具栏图标 → 填 **用户输入** + **指导输入（隐藏）** → **指导发送**。
3. 对不满意的助手回复，用 **指导修改** 而非普通再生。

---

## 对话导出（`conversation-export`）

**作用**：把当前对话导出为离线 **HTML** 文件。

| 在哪用 | 做什么 |
|--------|--------|
| 输入框工具栏 **导出对话为 HTML** | 选全部或指定回合范围 → 导出 |

在 **设置 → 插件 → 对话导出** 可配置是否包含思维链、元信息、头像及自定义 CSS。导出期间请勿同时发送消息。

---

## 滑动清理（`swipe-cleaner`）

**作用**：删除多余的 swipe 候选，只保留当前显示的那条，减小数据体积。

| 在哪用 | 做什么 |
|--------|--------|
| 助手消息下方 | **清理本回合其它滑动** |
| 输入框工具栏 | **清理本聊天全部滑动** |

操作**不可撤销**；清理前请确认当前 swipe 是你想保留的版本。

---

## 完成提示音（`reply-complete-sound`）

**作用**：助手回复**流式结束**后播放提示音。

| 在哪用 | 做什么 |
|--------|--------|
| **设置 → 插件 → 完成提示音** | 默认/自定义 MP3·WAV、音量、重复次数 |

无对话页按钮；保存后下一条回复完成即生效。可点 **试听** 确认音量。

---

## 自定义样式（`custom-styles`）

**作用**：向对话页注入自定义 **CSS**（气泡、背景等）。

| 在哪用 | 做什么 |
|--------|--------|
| **设置 → 插件 → 自定义样式** | 添加多条样式表、总开关 |
| **本对话设置 → 插件** | 本场继承/启用/禁用、按表覆盖 |

修改 CSS 后，**刷新页面或重新进入对话** 才会应用。自定义样式可能影响可读性，请自行承担风险。

---
