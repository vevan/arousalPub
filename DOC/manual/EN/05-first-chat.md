# 05 · Start your first chat

After this chapter: you created a conversation, sent a message, and saw a streaming model reply.

Prev: [04 · Character cards: import or create](04-characters.md) · Next: [06 · Common chat actions](06-chat-basics.md) · [Menu](00-menu.md) · [中文](../CN/05-first-chat.md)

---

## Prerequisites

- [01](01-install-and-start.md)–[03](03-connect-api.md) done; **Test connection** passed.
- [04](04-characters.md): at least one other character card in the library.

---

## Steps

### 1. New chat

On the home page click **New chat**.

### 2. Fill the create form

| Field | Suggestion |
|------|------|
| **Chat name** | Anything you can find later in the list |
| **User card** | Pick a user character (or whatever the UI offers if you have none yet) |
| **Main character card** | Pick the other character; use **Add character slot** for more (group chat: [14](14-group-and-branches.md)) |
| **Bound lorebooks** | Beginners can keep defaults or clear them; lorebooks: [08](08-lorebooks-intro.md) |

Click **Start chat**.

### 3. Send the first message

1. Type in the bottom composer.
2. Send (shortcuts: **Settings → System**).

With a good config, the assistant reply **streams** in. If the top bar still asks you to configure **Connection**, go back to [03 · Connect the API](03-connect-api.md).
