## Open the prompt library

Top bar **Prompts** → **Prompts** management UI.

Structure:

**Preset → group → entry**

Entries can set triggers, injection positions, and more. Beginners need not edit every entry at once: chat with a built-in or imported preset first, then tune.

---

## Set as default (global)

In the prompt library, you can **Set as default preset** for a preset.  
**Connection** can also **link a prompt preset** (often selected automatically when setting a global API preset).

The default affects chats that **follow global**.

---

## Bind to this chat

1. Open a chat.
2. **This chat settings → Bindings → Prompt preset**.
3. Pick a specific preset, or keep **Follow global current preset**.

Different chats under the same account can use different prompt strategies.

---

## Import presets from SillyTavern

- In the prompt library: **Import preset…**
- Or **Settings → Import**, then open the prompt library to import

Fuller migration notes: [16 · Migrating from SillyTavern](16-from-sillytavern.md).
