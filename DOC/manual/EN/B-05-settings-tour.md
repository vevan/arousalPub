# B-05 · Settings tour

After this chapter: you know what each Settings tab is for, so language, theme, and history depth are easy to find later.

## How to open

Top-bar **gear** → **Settings** (fullscreen modal). Left side is category navigation.

Note: API Key / model stay in top-bar **Connection**, not here (see [A-03](A-03-connect-api.md)).

---

## Tabs at a glance

| Tab | What you usually change |
|------|----------|
| **System** | UI language, chat font size, composer send shortcut, session chunking, etc. |
| **Account** | Avatar, password, default user, sign out, delete account (see [A-02](A-02-first-login.md)) |
| **Display** | Theme and primary color, home default view, etc. |
| **Chat history** | Whether to limit history turns, max turns in context |
| **Lorebook** | Global keyword recursion (book content is still edited on the Lorebooks page) |
| **Vector recall** | Embeddings, long-term memory, lorebook vectors, knowledge RAG — chapter [B-07](B-07-vector-recall.md) |
| **Budget trim** | Drop order when context exceeds budget |
| **Regex** | User-level regex pipeline — chapter [B-06](B-06-regex-rules.md) |
| **Plugins** | Enable, order, per-plugin settings (see [D-02](D-02-plugins-intro.md)) |
| **Import** | Import world info / presets / chats from SillyTavern (see [D-03](D-03-from-sillytavern.md)) |
| **Debug** | **Enable session debug audit**, version info, session audit (see [D-04](D-04-session-debug-audit.md)) |

---

## Two things beginners should set first

### Language

**Settings → System**: **Follow browser language** / **English** / **简体中文**.

### Theme

**Settings → Display**: pick theme and primary color for comfort.

Leave the rest until you need them.
